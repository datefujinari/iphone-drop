# phone-drop

iPhone の Safari から、同じ LAN の Windows PC に写真・動画を送る小さな受信サーバー。iPhone 側にアプリは不要。

## 準備

```
pip install --user segno
```

PC と iPhone を同じルーターにつなぐ。Windows のファイアウォール確認が出たら「プライベート ネットワーク」だけ許可する（ネットワークが「パブリック」だとつながらない）。

## 使い方

1. `phone-drop.bat` を実行 → PC のブラウザに QR コードが出る
2. iPhone のカメラで QR を読み取り、「写真を選ぶ」から送る
3. 保存先は既定で `ピクチャ\iPhone受信`。10分間なにもなければ自動終了（Ctrl+C でも止まる）

オプション: `--dir 保存先` `--minutes 分数` `--port 番号` `--no-browser`（QR を黒い画面に表示）

## 安全面

- 起動ごとの使い捨てトークンがない通信は拒否
- LAN の IP だけで待ち受け、一定時間で自動終了
- 受け取るのは写真・動画の拡張子だけ（1ファイル 4GB まで）。ファイル名は無害化し、保存先の外には書き込まない

**注意:** 通信は暗号化なしの HTTP。自宅など信頼できるネットワークでだけ使い、公共 Wi-Fi では使わない。
